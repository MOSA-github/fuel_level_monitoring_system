01 / 基準点・画像補正・針テスト

テスト用：カメラの最新画像を直接表示する（本番URL設定ではありません）

ここで入力するURLは即時テスト表示専用で、本番の自動更新には保存されません。本番は下の「カメラID」とGitHub Actions Secret CAMERA_SOURCES_JSON の対応を使います。ブラウザ内の「針の解析テスト」で画素を読むにはカメラ側のCORS許可が必要です。設置角度・画角が変わったときは再校正が必要です。

必須：①〜③を順番に指定

①と③までの距離から検出半径を自動決定します。現在の針先端を設定する必要はありません。

台形補正（計器面が斜めに写る場合のみ）

正面から撮れていて計器面が長方形ならOFFのままで構いません。ONにした場合、計器の平面部分の四隅を左上 → 右上 → 右下 → 左下の順に指定します。①〜③は元画像上で指定したままで、解析時に自動補正します。

04 / 本番へ反映

通常は、この3つだけで完了です

1上の「針の解析テスト」で正常に読めることを確認
2GitHubトークンを入力
3「設定を本番へ反映」を押す

これだけで config/gauges.json の更新・mainへのcommitまで自動で行います。 commit後はGitHub Actionsが自動起動するため、通常は別途commitや「今すぐ解析」は不要です。

病院ダッシュボード連携： 病院側には下の公開データURLを貼るだけで連携できます。施設ID・設備IDは公開データにも残りますが、1計器だけのURLなら病院側でIDを合わせる必要はありません。
