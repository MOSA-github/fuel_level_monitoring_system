CAMERA CALIBRATION

画像の上で、計器を設定。

①最小目盛 → ②針の回転中心 → ③最大目盛。3点だけを校正し、現在の針は更新のたびに自動検出します。

01 / 基準点を指定

カメラの最新画像を直接表示する

CORS不要で表示できます。表示できない場合は、カメラ画像を保存して読み込んでください。設置角度・画角が変わったときは再校正が必要です。

画像と同じ画角で①〜③を選びます。①と③までの距離から検出半径を自動決定し、定期実行では取得した最新画像ごとに針を自動検出します。

針の扱い
—
座標を数値で調整（0〜1）

02 / 設備と換算範囲

値 = 最小値 + 検出した針角度 ÷ ∠①②③ × (最大値 − 最小値)。選択した回転方向で角度を測ります。

03 / 自動解析

GitHub Actionsが5分ごとに起動し、設定間隔を過ぎた計器を解析します。起動遅延があるため厳密な時刻や即時実行は保証されません。

04 / 設定を保存・反映

下書き保存だけでは定期解析に反映されません。「GitHubへ反映」で config/gauges.json を更新するか、JSONを書き出してリポジトリへcommitしてください。設定・名称・施設IDは公開されます。
